# 塔塔能源森林：版本交付说明

记录日期：2026-09-14。此文件说明本轮单关卡版本的实际实现、美术资产和技术入口。当前已完成本地自动验证；公网部署及真实浏览器最终验收仍在进行，不能据此认定线上版本已经更新成功。

## 关卡与表现

主角为 TATTU 黄色闪电狼「塔塔」。单关卡名称为「第 1 关 · 点亮森林」，棋盘为 8 列 × 9 行。玩家在 30 步内收集 18 个黄色闪电塔塔、18 个青色飞行塔塔，并消除 18 块冰层。无效交换回弹且不扣步；冰层通过消除其上的棋子击碎。结算包含胜负、星级、剩余步数奖励和本地最高分。

- 三连消除；四连生成整行或整列闪电；T / L 连生成区域爆炸；五连生成彩虹核心。特殊棋子之间可组合，彩虹与普通棋子交换会清除对应颜色。
- 开局配置 3 个电能锤、2 个无人机区域爆炸、2 次重排。道具库存、目标数量及能量在操作后更新；无可用交换时自动重排。
- 满能量后可启动 15 秒超载。期间点击棋子直接触发消除，并获得音乐节拍同步反馈；输入队列设有上限，结束时等待当前结算完成、清除剩余排队点击。
- 棋子具备交换、无效回弹、消除前膨胀、下落和补充动画；塔塔使用配对睁眼／闭眼纹理实现错峰眨眼。
- 特效包含局部爆闪、星点碎片、冲击环、行列电弧、区域爆炸、彩虹连线、目标飞入面板、连击文字、超载节拍脉冲及胜利彩纸。背景有漂浮光点；设置提供「舒适动效」。
- 界面包含开局目标、步数与收集面板、星级进度、道具栏、提示、暂停设置、玩法说明、音乐试听、重开确认和胜负结算。

## 音乐与音效

`game/audio.mjs` 实现 10 段原创、程序化合成的电子编曲，每段 15 秒，速度范围 128–174 BPM。它们使用不同的鼓组节奏、低音、旋律、和弦和音色，并包含镲片、填充、上升音效、立体声延迟与后半段增强编排。这里的「10 段音乐」指这些现场合成编曲，不表示已购入或已授权的商业歌曲录音。

| 编号 | 名称 | BPM |
| --- | --- | --- |
| 01 | 雷霆起跑 | 132 |
| 02 | 霓虹追猎 | 174 |
| 03 | 晶能脉冲 | 142 |
| 04 | 超载重击 | 146 |
| 05 | FPV 穿云 | 164 |
| 06 | 午夜电路 | 128 |
| 07 | 黄金燃点 | 156 |
| 08 | 星环跃迁 | 140 |
| 09 | 裂空极速 | 172 |
| 10 | 塔塔觉醒 | 150 |

音乐与音效由原生 Web Audio 实现，经音量总线和压缩器输出；首次用户点击时解锁音频。浏览器自动播放策略可能阻止未交互页面发声，设备或系统静音也会影响实际播放。暂停保留曲目位置，恢复后继续，停止／销毁会清理音源与调度器。普通点击、交换、连消、特殊消除、目标收集、胜负结算均有独立音效。

手机震动是可关闭的增强反馈，依赖设备、浏览器及其 Vibration API 支持；不支持的平台仍可正常游玩，不能承诺所有手机都产生震动。

## 技术入口与维护

当前游戏使用 Phaser 3.90.0，目标画布为 720 × 1220，采用适配缩放、60 FPS 目标与 WebGL／Canvas 自动选择。游戏音频由独立 Web Audio 模块管理。

| 路径 | 职责 |
| --- | --- |
| `play.html` → `game/main.mjs` | 页面入口、Phaser 创建、加载错误提示与页面隐藏处理。 |
| `game/scene.mjs` | 关卡状态、棋子对象、输入、冰层、目标计数、HUD、弹窗、音画衔接。 |
| `game/model.mjs` | 无浏览器依赖的三消规则、特殊组合、道具、超载及死局恢复。 |
| `game/effects.mjs` | Phaser 特效对象、补间及清理，包含对象数量限制与舒适动效支持。 |
| `game/audio.mjs` | 10 段音乐、交互音效、节拍回调、静音／震动和生命周期管理。 |
| `game/ui.css` | 页面适配与覆盖在画布上的弹窗、设置及无障碍控件样式。 |
| `tests/model.test.mjs` | 规则与关键关卡状态回归测试。 |
| `vite.game.config.mjs`、`scripts/build-game.mjs` | 相对资源路径与静态构建；输出到 `dist-game/`，入口改名为 `index.html`，生成 `.nojekyll`。 |

规则层返回独立棋盘快照的动画帧序列（交换、回弹、消除、下落、重排）；后续计算不会改写已返回的帧。场景按序播放快照，并在完整结算后决定胜负，避免动画中空格被当成可操作的完整棋盘。这里的「不可变帧」是输入／快照互不改写的约定，不表示运行时对每个对象都执行 `Object.freeze()`。

常用命令：`npm run dev` 启动开发页，`npm test` 执行规则测试，`npm run build` 生成静态交付文件，`npm start` 启动构建预览。仓库中原有 `app/` 与旧工程文件继续保留；旧应用的构建命令为 `npm run build:legacy`，当前新游戏从 `play.html` 进入。

本轮本地测试结果为 19 项通过，其中包含固定随机种子的 1000 回合混合操作检查，覆盖稳定可玩棋盘、计分与收集统计、快照互不改写、特殊组合、死局、最后一步结算、超载到期及暂停时的中间动画状态。音频模块另通过语法与模拟 AudioContext 生命周期检查，覆盖十段音乐启动、暂停恢复、到期停止、静音和清理。

2026-09-14 已在应用内浏览器完成真实 UI 操作：点击交换、无效交换不扣步、滑动交换、连锁中暂停恢复、电能锤／无人机／重排、15 秒超载快速点击与队列、超载暂停后恢复、十段音乐按钮切换、三星通关、结算帮助返回和重新开局。该次通关得分 24,780，剩余 20 步。当前页面错误／警告日志为空。

375 × 812 视口实测游戏画布为 375 × 635.4，保持 720:1220 原始比例，避免角色和棋盘拉伸；纵向空余区域延续模糊森林背景。桌面侧栏常规尺寸也已查看整屏画面。

自动测试不能代替实际听感和真机测试。十段音乐确认可通过浏览器启动与切换且无报错，但本轮没有独立完成十段完整听感审听；手机实体震动仍取决于浏览器与设备支持，未宣称 iOS/Android 真机均已验证。公网验收另记于发布记录。本版不宣称已达到《开心消消乐》商业产品的全部制作水准。
